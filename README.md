# Papers to Read

想读、在读、读完的论文清单。

## 用法

- 看到想读的论文：加到「待读」，一行就够，写清楚为什么想读。
- 开始读：移到「在读」。需要记笔记就复制 [`notes/_template.md`](notes/_template.md)，改名为 `notes/年份-第一作者-关键词.md`。
- 读完：移到「已读」，写一句话结论。
- 让 agent 记录时，直接说「把这篇加到待读：<链接>，因为……」即可。

条目格式：

```
- [ ] 标题 — 作者, 年份, 会议/期刊 · [链接](url) · 标签 `#xxx` · 为什么想读
```

优先级：🔴 必读 · 🟡 有空读 · ⚪ 了解即可
